# KAMIS API 제공 여부 재검증 — 2026-10-10

## 결론

이전에 저장 가격이 없던 14개 코드 중 **13개는 일별 가격이 존재**한다.
`439 만감`은 아래 확인 범위에서 가격을 찾지 못했지만 영구 미제공으로 확정하지 않는다.
따라서 현재 **영구 제외할 품목 목록은 비어 있다.**

이 점검은 읽기 전용이다. 여기에서 새로 찾은 조합은 아직 수집 코드 보정 설정이나 가격 CSV에 반영하지 않았다.
이전의 32개 복구 결과와 이번의 13개 제공 확인을 혼동하지 않는다.

## 확인 범위와 증거

- [공식 Open API 안내](https://www.kamis.or.kr/customer/reference/openapi_list.do)의 번호 1~17 문서를 모두 읽었다.
- 서로 다른 action 17종을 실제 호출했다. 상세 후보 조회 824회와 최근 전체/지역 목록 2회, 총 826회다.
- 상세 조회에서 네트워크/HTTP/JSON 처리 예외는 0건이었다. 이것이 모든 요청의 업무 코드 `000` 또는 가격 반환을 의미하지는 않는다.
- 기본 기간: 2026-09-01~09-30, 2025-11-01~11-30. 일별 조회: 2026-10-08, 2025-11-14.
- 추가: 절임배추는 2024-11-01~11-30, 만감은 2025년 1월·2026년 1월·3월을 조회했다.
- 월·연간 조회에는 `p_yyyy=2026`을 요청했지만, **응답에는 2023·2024년 등 과거 연도도 있다. 요청 연도를 관측 연도로 덮어쓰지 않는다.**
- `convert_kg=N`, 기간 API는 전국 요청(`p_countrycode=''`). 카탈로그 품종과 등급에 `04/05/30` 후보를 더하고 도소매 양쪽을 검증했다.
- 친환경 API 4종은 친환경 등급이 있는 기장 `114:01:07`로 호출했다. 남은 14개에 친환경 등급이 없으므로 이 대조 조회를 14개 품목의 친환경 전수 조사로 해석하지 않는다.
- 모든 연도·모든 지역·모든 코드 조합을 전수 호출한 것은 아니다.

증거: [824개 요청의 파라미터 및 응답 요약](kamis-availability-probes-20261010.json).
`price_fields`는 양수인 가격 필드 개수이며, 공식 평균 관측 건수가 아니다. 지역값·최대값 등이 포함될 수 있다.
원 응답은 `tmp/kamis-all-api-probes.json`, `tmp/kamis-seasonal-final-probes.json`, 최근 목록은 `tmp/kamis-latest-inventory.json`에 있으며 인증 파라미터/condition은 제거했다.

## 후속 작업 원칙

1. 이 문서의 13개 조합을 보정 설정에 추가하려면 기존 유효 조합을 유지하고 단위를 함께 확인한다.
2. 실제 가격 복구는 별도 수행한다. 현재 이 문서는 가격 제공 확인 증거이지 CSV 저장 완료 기록이 아니다.
3. 월·연간 값이나 최신 스냅샷을 반복 복제해 20년 일별 가격으로 만들지 않는다.
4. API 업무코드 001, 처리 오류, 가격이 모두 '-'인 응답, 공식 평균만 없는 응답을 구분한다.
5. `439`는 새 카탈로그/유효 조합/출하기 자료가 확인되면 재검증한다. 자동 영구 제외로 만들지 않는다.
