## 1. 프로젝트 개요

KAMIS API에서 제공하는 전체 품목·품종의 도매가격과 소매가격을 기준으로 네이버·쿠팡의 실제 온라인 판매가격, 관련 원자재 선물가격, 국내외 주요 주가지수를 매일 한 번 수집한다. 모든 원본과 정규화 결과는 CSV로 보존하고 웹 대시보드에서 조회, 검색, 필터링, 비교, 시각화와 상관분석을 수행한다.

온라인 판매 여부는 미리 정하지 않는다. 각 KAMIS 품목을 온라인에서 실제로 검색한 뒤 비교 가능한 판매상품이 없을 때만 해당 플랫폼·해당 날짜의 온라인 비교에서 제외한다. 품목 자체는 KAMIS 수집과 다른 시장지표 분석에서 계속 유지한다.

가격과 주가지수의 단위가 다르므로 원값은 조회용으로 제공하고, 실제 비교와 상관분석은 선택 기간 첫 유효값을 100으로 환산한 지수와 일간·7일 변화율을 중심으로 수행한다. 결과는 인과관계가 아니라 동행성·선행성·후행성을 탐색한 통계적 관계로 해석한다.

### 핵심 연구 질문

1. KAMIS 도매가격 변화는 KAMIS 소매가격과 네이버·쿠팡 판매가격에 어느 정도 시차를 두고 반영되는가?
2. 같은 품목의 KAMIS 소매가격과 네이버·쿠팡 단위가격은 얼마나 차이가 나는가?
3. 네이버와 쿠팡의 대표가격 및 두 플랫폼의 통합 평균은 서로 비슷하게 움직이는가?
4. 경제적으로 연결 가능한 원자재 선물가격은 해당 KAMIS 품목 가격에 선행하거나 동행하는가?
5. KOSPI, KOSDAQ, S&P 500, NASDAQ Composite, Dow Jones와 농수산물 가격 변화 사이에 통계적 관계가 있는가?
6. 가격 수준에서 보이는 관계가 변화율과 시차를 적용한 뒤에도 유지되는가?

## 2. 공모전 활용 전략

| 평가 관점 | 대응 전략 |
|---|---|
| KAMIS 활용 적합성 | KAMIS 전체 품목·품종과 도매·소매가격을 데이터 모델의 기준축으로 사용한다. |
| 충실성 | 매일 실행 로그, 원본·정규화 CSV, 상품 선정·제외 근거와 수집 성공률을 남긴다. |
| 실용성 | 소비자가 온라인 판매가격과 KAMIS 소매가격의 차이를 품목별로 확인할 수 있게 한다. |
| 확산 가능성 | 연구자와 유통 종사자가 품목·시장별 가격 변화와 시차 상관을 탐색할 수 있게 한다. |
| 투명성 | 표본 수, 결측률, 상품 매칭 등급, 이상치 제외 내역과 분석 한계를 공개한다. |

보고서의 핵심 주장은 “가격의 원인을 규명했다”가 아니라 **KAMIS 전 품목을 여러 시장 데이터와 연결하고 실제 비교 가능한 분석 기반을 구축·운영했다**로 설정한다.

## 3. 데이터 범위

### 3.1 KAMIS API

| 용도 | action | 비고 |
|---|---|---|
| 품목·품종·단위·등급 사전 | productInfo | 전체 수집 대상과 온라인 상품 매핑의 기준 |
| 기간별 도매가격 | periodWholesaleProductList | 기간 설정 가능, 요청당 최대 1년 |
| 기간별 소매가격 | periodRetailProductList | 기간 설정 가능, 요청당 최대 1년 |

공통 요청 URL은 https://www.kamis.or.kr/service/price/xml.do 이며 가격 API는 인증키와 요청자 ID가 필요하다. p_convert_kg_yn=Y를 우선 사용하되 개수·마리·단 등의 단위는 품목별 환산 규칙을 적용한다.

기획 단계에서 productInfo 응답의 212개 품종 행을 확인했다. 이 수는 실제 가격이 있는 품목·품종의 수와 항상 같지 않으므로 운영 시 매일 품목 사전과 가격 응답을 대조한다.

- API에서 확인되는 전체 품목·품종을 수집 대상으로 등록한다.
- 특정 날짜에 가격이 없어도 품목을 마스터 목록에서 제거하지 않는다.
- 도매와 소매를 분리하고 품목, 품종, 등급, 지역, 단위를 보존한다.
- 과거 3년 자료를 1년 단위로 백필하고 이후 매일 증분 수집한다.
- 관측일 observed_date와 수집 시각 collected_at을 분리한다.

### 3.2 네이버·쿠팡 판매가격

네이버와 쿠팡은 독립된 가격 소스로 취급한다. 기존 추적 상품이 모두 품절·판매 종료되면 해당 품목을 다시 검색하며, 재검색 결과에도 비교 가능한 상품이 없을 때만 그 플랫폼·해당 날짜를 온라인 판매 불가로 기록한다.

네이버 쇼핑 검색 Open API는 2026-07-31 종료되었고, 쿠팡의 일반 Open API는 판매자 상품·주문·재고 관리용이다. 공식적으로 사용할 수 있는 신규 가격 API나 제휴 권한을 우선 확인한다. 공개 웹페이지를 수집할 때는 이용약관과 robots.txt를 확인하고 로그인·CAPTCHA·차단을 우회하지 않는다. 정책상 자동 수집이 허용되지 않는 소스는 중단하고 상태를 대시보드에 공개한다.

### 3.3 원자재 선물·환율

원자재 선물은 경제적 연관성이 있는 경우에만 market_mapping.csv로 품목과 연결한다. 예를 들어 콩은 대두 선물, 쌀은 쌀 선물, 오렌지는 오렌지주스 선물과 연결하되 상품 차이와 한계를 표시한다. 달러 표시 선물은 원가격과 USD/KRW 환율을 적용한 원화 환산가격을 함께 저장한다.

적합한 선물이 없는 품목은 선물 매핑 없음으로 표시하되 KAMIS·온라인·주가지수 비교에서는 제외하지 않는다.

### 3.4 주가지수

모든 KAMIS 품목에 다음 지수를 공통 비교 변수로 연결한다.

- KOSPI
- KOSDAQ
- S&P 500
- NASDAQ Composite
- Dow Jones Industrial Average

주가지수는 품목 가격의 직접 원인으로 전제하지 않고 시장 환경과의 동행 여부를 확인하는 공통 비교·대조 변수로 사용한다.

## 4. 온라인 판매상품 선정과 대표가격

### 4.1 적응형 상품 추적

1. KAMIS 품목명, 품종, 원산지, 규격을 조합해 온라인 판매상품 후보를 검색한다.
2. 비교 가능한 상품과 예비 상품을 등록하고 매일 가격과 판매 상태를 확인한다.
3. 기존 상품이 품절·판매 종료되거나 정상 표본이 부족하면 해당 품목을 다시 검색한다.
4. 재검색에도 유효 상품이 없으면 해당 플랫폼·날짜만 온라인 판매 불가로 기록한다.
5. 판매가 재개되거나 새로운 적합 상품이 발견되면 자동으로 비교에 복귀시킨다.

### 4.2 포함·제외 규칙

- 품목, 품종, 원산지, 등급, 포장 중량을 별도 필드로 분리한다.
- 묶음 상품은 총중량으로 환산한다.
- 상품가격과 배송비를 합한 실제 결제금액을 비교단위 가격으로 환산한다.
- 무료 회원가입자 모두에게 자동 적용되는 할인가는 포함한다.
- 유료 멤버십, 특정 카드·결제수단, 첫 구매, 개인 쿠폰, 타깃 할인은 대표가격에서 제외한다.
- 식품이 아닌 상품, 중고, 렌탈, 중량 불명, 품종·원산지 불일치 상품은 제외한다.
- 해외직구는 기본 제외한다.
- 매칭 결과를 exact, compatible, rejected로 기록하고 대표가격에는 exact와 compatible만 사용한다.

### 4.3 저가 이상치 제거와 평균

플랫폼별 대표가격은 다음 순서로 계산한다.

1. 유효 후보의 배송비 포함 단위가격을 오름차순으로 정렬한다.
2. 최저가를 그다음 후보 최대 5개의 평균과 비교한다.
3. 최저가가 비교 평균보다 15% 이상 저렴하면 제외한다.
4. 다음 최저가부터 같은 검사를 반복한다.
5. 남은 상품 중 저렴한 상품 최대 5개를 선택해 산술평균을 계산한다.

정상 상품이 5개 미만이어도 남은 상품만으로 평균을 계산한다. 후속 상품이 부족해 15% 검사를 할 수 없으면 제거하지 않고 표본 수를 표시한다. 상품이 하나도 없을 때만 결측 처리한다. 제외 상품과 사유는 모두 보존한다.

| 통계 | 정의 |
|---|---|
| 네이버 평균 | 이상치를 제거한 뒤 선택된 최대 5개 상품의 평균 |
| 쿠팡 평균 | 이상치를 제거한 뒤 선택된 최대 5개 상품의 평균 |
| 통합 온라인 평균 | 네이버 평균과 쿠팡 평균의 산술평균 |
| 플랫폼별 표본 수 | 평균에 실제 사용된 상품 수 |

통합 평균은 플랫폼별 평균에 같은 가중치를 준다. 한 플랫폼만 값이 있는 날에는 통합 평균을 만들지 않고 해당 플랫폼 값만 표시한다.

## 5. 일일 수집·저장 설계

### 5.1 하루 한 번 실행되는 배치

1. run_id와 수집 기준시각 생성
2. KAMIS 품목 사전 및 최신 도매·소매가격 수집
3. 네이버·쿠팡 추적 상품의 가격과 판매 상태 확인
4. 표본 부족·품절 품목의 온라인 판매상품 재검색
5. 원자재 선물·USD/KRW·5개 주가지수 수집
6. 소스별 원본 CSV 저장
7. 품목 매핑, 할인 조건, 배송비, 단위가격 정규화
8. 저가 이상치 제거 및 플랫폼별·통합 평균 계산
9. 기준일 100 지수, 변화율, 상관분석용 패널 생성
10. 품질검사 결과와 소스별 성공·실패 상태 기록

한 소스의 실패가 전체 배치를 중단시키지 않도록 독립 실행한다. 제한된 재시도 후 실패하면 결측으로 유지하고 이전 가격으로 채우지 않는다.

### 5.2 디렉터리와 CSV

- data/raw: kamis, naver, coupang, market의 날짜별 원본 CSV
- data/normalized: KAMIS 가격, 온라인 개별상품·플랫폼 통계, 시장 데이터 CSV
- data/analytics: 일별 비교 패널, 상관·시차 상관, 품질 통계 CSV
- data/metadata: KAMIS 품목 사전, 상품 매핑, 시장 매핑, 소스 등록부 CSV
- logs: 날짜별 실행 로그

CSV를 원본 저장소로 사용한다. 웹 조회 성능이 부족하면 DuckDB를 읽기 캐시로 사용할 수 있지만 언제든 CSV로 재생성할 수 있는 파생물로 둔다.

핵심 필드는 실행 ID, 출처, 관측일, 수집시각, 품목·품종·등급·원산지·지역 코드, 판매자·상품 ID·URL, 포장 수량과 단위, 정상가·할인가·배송비·총액·단위가격, 할인 조건, 판매 상태, 매칭 등급, 제외 사유, 평균 포함 여부와 표본 수이다.

## 6. 날짜 정렬과 분석

### 6.1 거래일 처리

- 원본 CSV에는 실제 수집 결과를 모두 보존한다.
- 분석 패널과 그래프 X축에서는 주말·공휴일을 제외한다.
- KAMIS의 새로운 가격이 실제 관측된 영업일을 기본 X축으로 사용한다.
- 휴일 가격을 직전 영업일 값으로 채우거나 반복하지 않는다.
- 해외시장 휴일로 지수·선물 값이 없으면 공백으로 둔다.
- 상관분석은 두 변수의 값이 모두 존재하는 공통 관측일만 사용한다.

### 6.2 비교 지표

| 계층 | 지표 | 용도 |
|---|---|---|
| 원값 | KAMIS·온라인 가격, 선물가격, 주가지수 | 실제 관측값 확인 |
| 지수화 | 선택 기간 첫 유효값=100 | 서로 다른 단위의 통합 그래프 |
| 변화율 | 1영업일 및 7영업일 변화율 | 공통 추세로 인한 허위상관 완화 |
| 스프레드 | 온라인-KAMIS 소매, 소매-도매 | 유통 단계별 가격 차이 |
| 변동성 | 7일·30일 이동 변동성 | 시장별 가격 안정성 비교 |

### 6.3 상관관계

Pearson과 Spearman 상관계수, -14영업일에서 +14영업일까지의 시차 상관, 30일·60일 이동 상관을 계산한다. 모든 결과에 관측치 수, 결측률, p-value를 표시하며 다중 비교에는 FDR 보정을 적용한다.

KAMIS·선물·주가지수는 과거 3년을 백필한다. 네이버·쿠팡은 자동 수집 시작일부터 누적하므로 초기 결과는 파일럿 관측으로 표현한다. 상관관계를 인과관계로 표현하지 않는다.

## 7. 웹 대시보드

### 7.1 전체 품목 현황

- KAMIS 전체 품목 수와 당일 가격 관측 품목 수
- 네이버·쿠팡 비교 가능·판매 불가·수집 실패 품목 수
- 소스별 마지막 성공 시각과 최신·지연·실패 상태
- 품목별 KAMIS 도매·소매, 네이버, 쿠팡, 통합 평균
- 품목명 검색과 부류·품종·등급·날짜 필터

### 7.2 품목별 통합 비교 그래프

기본 그래프에는 KAMIS 도매가격, KAMIS 소매가격, 네이버 평균가격, 쿠팡 평균가격, KOSPI, KOSDAQ, S&P 500, NASDAQ Composite, Dow Jones Industrial Average와 해당 품목에 연결된 원자재 선물을 한 번에 표시한다. 통합 온라인 평균은 점선 보조 지표로 제공한다.

기본 모드는 선택 기간 첫 유효값=100이며 원값, 기준일 100, 일간 변화율, 7일 변화율을 전환할 수 있다. 모든 시계열은 체크박스와 그래프 범례로 개별 활성화·비활성화할 수 있다. 툴팁에는 원값, 지수화 값, 변화율, 실제 관측일과 온라인 평균 표본 수를 표시한다.

### 7.3 상관관계 탐색기

- 기준 품목·품종·기간 선택
- 비교 변수 다중 선택과 Pearson·Spearman 전환
- 상관계수 히트맵, 산점도와 추세선
- -14~+14영업일 시차 상관 및 30일·60일 이동 상관
- 관측치 수, 결측률, p-value와 FDR 보정 결과

### 7.4 데이터 조회

CSV 다운로드 기능은 제공하지 않는다. 내부 CSV의 사용자 필요 정보를 웹 테이블로 표시한다.

- 날짜 범위, 품목, 품종, 등급, 원산지와 출처 필터
- 상품명과 품목명 통합 검색
- 정상·품절·판매 불가·저가 이상치·규격 불일치 상태 필터
- 가격, 배송비, 단위가격, 할인 조건, 매칭 등급 표시
- 평균 포함 여부, 제외 사유, 플랫폼별 표본 수 표시
- 열 정렬, 페이지 이동, 표시 열 선택
- 온라인 판매상품 원본과 일별 집계 통계 탭 분리

### 7.5 데이터 품질

소스별 성공률과 마지막 성공 시각, 품목별 결측률과 온라인 판매 가능률, 매칭 등급·제외 사유·표본 수 분포, 단위환산 및 날짜 정렬 실패 목록을 표시한다.

## 8. 품질검사와 테스트

자동 품질검사 항목은 중복, 0원·음수 가격, 단위환산, 배송비 포함 총액, 무료 회원 할인 판정, 정확히 15%인 저가 이상치 경계, 5개 미만 평균, 오매칭, 휴일 제외, 결측 미보간, 거래일 정렬과 상관분석 최소 관측치이다.

테스트는 KAMIS API 및 온라인 페이지 파서, 상품 매칭, 할인 조건, 배송비·중량 환산, 이상치·평균 계산, 휴일·결측·중복 처리, 기준일 100·변화율, 상관·시차 정렬, 웹 검색·필터·시계열 활성화를 대상으로 한다.

## 10. 범위와 실패 대비

### 반드시 완성할 범위

- KAMIS API 제공 전체 품목·품종의 마스터와 일일 도매·소매가격
- 네이버·쿠팡의 전체 품목 검색과 적응형 상품 추적
- 플랫폼별 가격과 통합 온라인 평균
- 관련 원자재 선물과 5개 주가지수
- 원본·정규화·분석 CSV 계층
- 통합 비교 그래프, 상관관계 탐색기, 데이터 조회, 품질 화면
- 매일 한 번 자동 수집한 실행 로그와 성공률

### 실패·중단 기준

- 플랫폼이 자동 수집을 허용하지 않으면 우회하지 않고 해당 수집을 중단한다.
- 상품이 검색되지 않으면 해당 플랫폼·날짜만 판매 불가로 표시한다.
- 중량·품종·원산지를 신뢰성 있게 매칭할 수 없으면 비교 평균에서 제외한다.
- 시장 데이터가 없는 날은 이전 값으로 채우지 않는다.
- 관측치가 부족하면 결과를 참고값으로 표시하거나 숨기고 확정적으로 해석하지 않는다.
- 특정 소스가 실패해도 나머지 수집·저장·대시보드 갱신은 계속한다.

## 13. 주요 위험과 대응

1. **온라인 플랫폼 정책**: 공식 API·제휴 권한을 우선하고 접근 제한을 우회하지 않는다.
2. **전체 품목 검색량**: 정상·예비 상품을 추적하고 표본 부족 품목만 재검색한다.
3. **상품 오매칭**: 품종·원산지·중량·등급을 분리하고 매칭 등급과 제외 근거를 공개한다.
4. **비정상 저가**: 다음 후보 최대 5개의 평균보다 15% 이상 저렴한 값을 제외한다.
5. **회원 할인 판정**: 누구나 무료 가입 후 자동 적용받는 할인만 포함한다.
6. **표본 부족**: 5개 미만이어도 남은 상품 평균과 표본 수를 함께 표시한다.
7. **휴일 불일치**: 실제 관측 영업일만 사용하고 결측을 보간하거나 반복하지 않는다.
8. **허위상관**: 변화율·시차·표본 수·FDR 보정 결과를 함께 제시한다.
9. **온라인 기간 부족**: KAMIS·시장 데이터는 3년을 백필하고 온라인은 파일럿으로 구분한다.
